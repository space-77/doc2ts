## Purpose

保证 doc2ts 在多个数据源（origin）并发生成代码时，tag 名称翻译的过程状态、译名回写与字典缓存彼此隔离；并保证同一数据源内共享同一 tag 的全部 operation 都被正确翻译，使首次生成即产出英文文件名与完整的翻译字典，无需二次运行。

## ADDED Requirements

### Requirement: 翻译状态按数据源隔离

每个数据源（origin）的文档翻译过程 SHALL 独立持有其 tag 翻译去重状态，不得与其他数据源共享。任一数据源的翻译过程 SHALL NOT 因另一数据源已处理过同名 tag 而改变自身行为或跳过自身的译名回写与字典记录。

#### Scenario: 首次运行并发处理多个数据源

- **WHEN** 在翻译字典为空（首次运行）的情况下，配置了多个数据源并通过并发方式同时处理，且其中至少两个数据源包含同名中文 tag
- **THEN** 每个数据源的 tag 均被翻译为英文，所有数据源生成的模块文件名均为英文，不出现中文文件名

#### Scenario: 翻译状态不跨数据源泄漏

- **WHEN** 数据源 A 先注册并翻译了中文 tag `T`，数据源 B 随后处理同一中文 tag `T`
- **THEN** 数据源 B 独立完成 `T` 的译名获取与回写，其行为与未见过 `T` 时一致，不受数据源 A 处理进度或结果影响

#### Scenario: 处理顺序与完成时序不影响结果

- **WHEN** 多个数据源的翻译 Promise 以任意顺序完成，包括数据源 B 先于数据源 A 完成
- **THEN** 每个数据源产出的模块名与字典内容，与该数据源单独处理时的结果一致

### Requirement: 字典缓存完整记录每个数据源

每个数据源 SHALL 将其处理到的中文 tag 的 `zh → en` 映射写入自身的翻译字典。即使该 tag 的译名来自已存在的翻译条目，SHALL 仍然记录到当前数据源的字典中。

#### Scenario: 命中已有译名时仍写入字典

- **WHEN** 某数据源处理的中文 tag 已存在于翻译列表中（即命中已有译名）
- **THEN** 该数据源的字典文件包含该 tag 的 `zh → en` 条目，不出现字典为空数组的情况

#### Scenario: 首次运行后字典即可复用

- **WHEN** 首次运行生成完成后，使用首次运行产出的字典文件再次运行同一配置
- **THEN** 第二次运行直接复用字典中的译名，产出与首次运行一致，无需任何人工补充翻译

### Requirement: 同一数据源内共享 tag 的全部 operation 被翻译

当同一数据源内多个 operation 引用同一中文 tag 时，该 tag 在所有 operation 的 `tags` 数组中的对应元素 SHALL 均被替换为译名，且替换位置 SHALL 与该 tag 在各自数组中的实际索引一致。

#### Scenario: 同一 tag 位于不同索引位置

- **WHEN** 同一数据源内 operation `/a` 的 tags 为 `[审计, 用户]`（审计在索引 0），operation `/c` 的 tags 为 `[其他, 审计]`（审计在索引 1）
- **THEN** `/a` 的 tags 变为 `[Audit, User]`，`/c` 的 tags 变为 `[Other, Audit]`，两处均无中文残留

#### Scenario: 同一 tag 被多个 operation 引用

- **WHEN** 同一数据源内三个 operation 均引用中文 tag `审计`
- **THEN** 三个 operation 的 tags 中 `审计` 全部替换为 `Audit`，模块名生成阶段不再出现中文 tag，模块名唯一且均为英文

### Requirement: 首次生成即产出正确结果

在翻译字典为空的首次运行中，生成结果 SHALL 与字典已就绪的后续运行一致：模块文件名全部为英文，字典文件包含全部已处理 tag 的映射，不依赖二次运行修正。

#### Scenario: 删除输出目录后首次运行

- **WHEN** 删除输出目录（含字典文件）后，在翻译字典为空的状态下执行一次生成
- **THEN** 生成的模块文件名为英文，字典文件包含该数据源的 `zh → en` 条目，无需再次运行
