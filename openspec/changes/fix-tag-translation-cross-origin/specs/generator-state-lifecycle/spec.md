## Purpose

保证 doc2ts 在一次进程内多次执行生成（多次 `build()`）时，各模块级累加器不残留上一次运行的数据，使生成结果只取决于当前输入，而非历史调用次数。

## ADDED Requirements

### Requirement: 每次生成开始前重置模块级累加器

生成入口 SHALL 在每次执行开始时重置所有模块级累加器（待写入文件列表、barrel 导出条目、自定义类型列表、类型字符串列表），使同一进程内的连续多次生成互不污染。生成结果 SHALL 与调用次数无关。

#### Scenario: 同一进程内连续执行两次生成

- **WHEN** 在同一进程内连续调用两次生成，且两次输入相同
- **THEN** 两次生成的 `index.ts` 内容逐字节一致，不出现 `buddyAudit1` 这类因累积而追加的后缀

#### Scenario: 重置后累加器为空

- **WHEN** 在一次生成完成后执行重置
- **THEN** 待写入文件列表、barrel 导出条目、自定义类型列表、类型字符串列表的长度均为 0

#### Scenario: 第二次生成不受第一次残留影响

- **WHEN** 第一次生成累积了若干条目，随后开始第二次生成
- **THEN** 第二次生成产出的导出条目数量与仅执行一次时相同
